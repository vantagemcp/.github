# Vantage

Checks whether ChatGPT, Gemini and Perplexity cite your site, from inside your coding agent.

- [vantage-mcp](https://github.com/vantagemcp/vantage-mcp): the MCP server, MIT licensed
- [Hosted server and free check](https://vantagemcp.dev/?ref=gh-org): 30 units a month, no card
- [Monthly research](https://vantagemcp.dev/research?ref=gh-org): what ChatGPT, Gemini and Perplexity cite, with raw data
- Official MCP Registry: `dev.vantagemcp/vantage`
